# DataInsight Pro – AI Powered Data Analytics Platform

An enterprise-grade, production-ready web application built with Python and Streamlit for comprehensive data analytics.

## Features
- **Module 1:** Authentication (Login, Signup, Session Management, Role-Based Access)
- **Module 2:** Dataset Manager (Upload CSV, Excel, JSON, maintain history)
- **Module 3:** Data Cleaning (Missing values, Outliers, Encoding, Scaling)
- **Module 4:** Exploratory Data Analysis (Automated profiling, Interactive charts)
- **Module 5:** Dashboard Builder (Interactive, drag-and-drop style components)
- **Module 6:** Data Preprocessing Pipelines
- **Module 7:** Machine Learning (Regression, Classification, Clustering with auto-comparison)
- **Module 8:** AI Insights (Business summaries and automated data quality scoring)
- **Module 9:** Reports Generation
- **Module 10:** Database Integration (SQLite/PostgreSQL)
- **Module 11:** Activity Logs
- **Module 12:** Settings & Configurations

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd data
   ```

2. **Create a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Mac/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application:**
   ```bash
   streamlit run app.py
   ```

## Architecture
Built adhering to SOLID principles and Clean Architecture, utilizing Streamlit's latest layout, caching, and state management features.
